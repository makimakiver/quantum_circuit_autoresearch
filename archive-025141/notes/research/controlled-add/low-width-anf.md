# Low-width controlled addition: no gain at one or two bits

## Scope

This is the first bounded pass for [the active focus](../../focus/focus-captain-ahab-controlled-add-gap.md). The map is the no-carry-out controlled addition

`(c, a, b) -> (c, a, b + c*a mod 2^n)`.

The count intentionally excludes chunk-boundary carry comparators and empirical stream stripping. It counts CCX only and permits the same measurement cleanup model as the live circuit. See [captured live source](../../raw/controlled-add-live-source-2026-08-21.md).

## Result

| Width | Live threaded count | Direct required nonlinear terms | Conclusion |
|---:|---:|---|---|
| 1 | 1 | `c*a0` | exact by degree-two necessity |
| 2 | 3 | `c*a0`, `c*a1`, and the dependent product `(c*a0)*b0` | exact in the two-AND XAG model |

For no carry-out, `controlled_clean_add_threaded` has `s - 1` forward carry CCX gates and `s` controlled-sum CCX gates: `2s - 1`. With a carry-out it instead produces `s` carries, emits `s` controlled sums, and has one additional controlled carry-out CCX: the live local target is `2s + 1`, not `2s - 1`. This corrects the initial focus-card accounting.

## Derivation

At width one, the only changed output is

`b0' = b0 XOR (c*a0)`.

It needs one nonlinear product and the live construction emits one CCX.

At width two,

`b0' = b0 XOR (c*a0)`,

`b1' = b1 XOR (c*a1) XOR (c*a0*b0)`.

The cubic term requires a nonlinear value depending on `c*a0` before it can be multiplied by `b0`; the independent quadratic term `c*a1` is not generated by that dependency in the threaded realization. The three displayed nonlinear obligations are exactly the three CCX operations supplied by the threaded construction.

The new exact check [`y7_controlled_add_xag.py`](../../../src/point_add/memory/repro/y7_controlled_add_xag.py) removes the width-two uncertainty within its stated model. It truth-tables all 684 distinct first AND functions over the five inputs. Modulo affine functions, a two-AND realization must span the two independent nonlinear outputs. The first AND therefore must equal the unique quadratic direction `c*a0` modulo affine terms; exactly 4 first-AND functions meet that condition. The checker enumerates all 9,472 distinct second-AND functions reachable from those four first functions and finds zero functions that supply the required second nonlinear direction. Its accompanying unit test passes.

This is still not a claimed general lower bound: it is limited to a two-AND XAG with affine gate inputs and final affine output decoding. It does, however, include ordinary CCX/CNOT/X implementations at this width. HMR cleanup does not create a missing Boolean nonlinear value, so the live carry-erasure mechanism does not invalidate this classical-map obstruction.

## Consequence for synthesis

A low-width search cannot use `n=1` or `n=2` as evidence for a scalable improvement: a purported 0- or 2-CCX no-carry witness contradicts the bounded XAG checks, while a 3-CCX width-two witness merely rediscovers the baseline. The first potentially discriminating no-carry instance is width three (baseline five CCX); carry-out cases must be modeled separately because their live target is `2s + 1`.

The current SAT-oriented retained tool `y1_composite_synth.py` has the appropriate XOR/AND Tseitin and semantic-replay pattern, but this environment exposes neither `kissat` nor `cadical`. The bundled tests for that tool and the new width-two exhaustive check pass when run from `src/point_add/memory/repro`; no SAT result has been claimed.

## Next

1. Encode width-three no-carry controlled addition in the retained XOR/AND framework and seek a `<5`-AND UNSAT/SAT certificate once a pinned solver is available. Expected payoff: falsifies or supports the first nontrivial family member. Risk: XOR/AND synthesis does not itself model measurement cleanup, so a positive witness needs a separate clean implementation.
2. Encode width-two and width-three carry-out variants separately, with live targets 5 and 7 CCX. Expected payoff: prevents mixing the two contracts in future comparisons. Risk: the carry-out bit may make the unrestricted ANF search harder.
3. If neither family improves at width three, pivot from generic synthesis to source-state restrictions at actual GCD call sites; those restrictions could lower the effective map complexity without claiming a general adder improvement.
